How to get a Client ID & folder ID
  1. Go to console.cloud.google.com → create/select a project.
  2. Enable the Google Drive API (APIs & Services → Library).
  3. APIs & Services → Credentials → Create Credentials → OAuth client ID → type Web application.
  4. Under Authorized JavaScript origins add https://app.prismxe.com → Create → copy the Client ID here.
  5. In Google Drive, open/create the destination folder and copy the ID from the URL: drive.google.com/drive/folders/<FOLDER_ID>.
